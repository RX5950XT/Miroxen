      Base URL 可直接複製；點網址查看模型清單。

        其他區網電腦怎麼用？

        1. 兩台電腦連到同一個路由器／Wi-Fi。這台電腦需保持 Miroxen 執行。
        2. 在另一台電腦的瀏覽器開啟上方的「工作台」網址，就能直接生成，不必安裝模型。
        3. 若使用其他程式，將 API Base URL 填成 ；服務有設金鑰時，填相同的 API key。

        圖片程式需支援 OpenAI 圖片生成端點。一般聊天介面無法把本服務當成聊天模型；影音使用 Miroxen 的工作 API。

        連不上或要用程式呼叫？

        不要填 127.0.0.1 或 localhost，這兩個只會連到對方自己的電腦。多張網卡時，選與對方同網段的網址；VPN 網址需雙方都連上該 VPN。

        先開 /health，看到 status: ok 表示通了。若連不上，檢查 Windows 防火牆是否允許這台電腦的 TCP 8188 入站，以及路由器是否隔離裝置。防火牆設定需要管理員權限。

        POST 圖片生成至 /v1/images/generations（model: qwen-image-2.1）；POST 影音或非同步工作至 /v1/jobs。JSON 範例在下方，Content-Type 使用 application/json；有金鑰時加 Authorization: Bearer <API key>。
