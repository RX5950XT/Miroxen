              連線

                其他區網電腦怎麼用

                1. 兩台電腦連到同一個路由器／Wi-Fi，這台保持 Miroxen 執行。
                2. 另一台用瀏覽器開上方「工作台」網址即可生成，不必安裝模型。
                3. 其他程式把 API Base URL 填 ；服務有設金鑰時填相同的 API key。
                連不上？

                不要填 127.0.0.1 或 localhost，那只會連到對方自己的電腦。多張網卡時選同網段的網址；VPN 網址需雙方都連上。先開 /health，看到 status: ok 就是通了；否則檢查 Windows 防火牆是否允許 TCP 8188 入站、路由器是否隔離裝置。

                目前設定的請求

                依創作頁設定即時產生，POST 到 /v1/jobs。預覽省略素材內容；複製時包含 base64。
